# PLJA Live Scanner data

Public snapshots for https://plja-corp.pages.dev/live/.

This branch holds only scrubbed counts: tickers, talk volume, x-normal, price moves and a news-count flag. It does not hold analyst notes, emails, or copied social posts.

A free GitHub Action tries to refresh `board.json` every 15 minutes on weekdays. Scheduled runs can be delayed by GitHub.

Research and education only. Not investment advice.
