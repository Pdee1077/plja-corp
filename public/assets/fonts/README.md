# Fonts

These files are subsets of two SIL Open Font License (OFL 1.1) families, for this site only:

- **Fraunces** (semibold instance), by Undercase Type. [OFL](https://github.com/undercasetype/Fraunces/blob/master/OFL.txt)
- **IBM Plex Sans** (regular and medium instances), by IBM. [OFL](https://github.com/IBM/plex/blob/master/LICENSE.txt)

They are not the complete fonts. See the official repositories for the full license text, reserved font names, and the complete family.
